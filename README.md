# Tile Room

A first-person movement shooter prototype: three.js for rendering, Rapier for physics, Vite + TypeScript.

**Play:** https://mrratburnfailedme.github.io/tile-room/ (arena) · https://mrratburnfailedme.github.io/tile-room/?level=gym (movement gym)

## Controls

| | |
|---|---|
| Click | capture the mouse |
| WASD / Space / Shift | move / jump and wall-jump / sprint |
| C or Ctrl | slide |
| Left mouse (or F) | fire; an empty gun is thrown |
| Right mouse (or G) | throw the gun |
| E | pick up / swap gun |
| R / T | respawn at checkpoint / restart the gym run |
| L | switch level |
| F1 / F2 / F3 | free-fly camera / FXAA / stats |

## Develop

```bash
npm install
npm run dev
npm test
npm run build
```
